# BPMN_IQ_8

## Project shape
- Yarn workspaces monorepo, two independent apps: [client/](client/) (Vite + React + TS, Ant Design, react-plotly.js) and [server/](server/) (Node/Express + Mongoose/MongoDB).
- Root `yarn dev` runs both concurrently (`predev` runs [scripts/cleanup.bat](scripts/cleanup.bat) first); server serves an `/api/health` check the client waits on.
- Server domain: BPMN business-flow/process modeling — models for Components, Diagrams, Capabilities, Servers, Databases, Tasks, StatusRef, ApplicationFeatureDevCost, etc. under [server/models/](server/models/), routes under [server/routes/](server/routes/).
- Most of [server/](server/) root is one-off inspect/check/backfill/migration scripts (`check_*`, `inspect_*`, `_tmp_*`, `seed_*`) run ad hoc against the live DB — not part of the app runtime.
- Main client UI entry point under active development: [client/src/components/Dashboard.tsx](client/src/components/Dashboard.tsx) (large file — FlowDashboard, YoY Feature Cost 3D chart, US Server Map, SearchAll tab, Business Flow risk rows, etc).
